# 🎮 Найди друг друга ❤️

**Top-down RPG** — городское приключение для двоих!

## 🌆 Концепция

Выберите персонажа (Саша или Аня) и пройдите через целый город, чтобы найти свою половинку!

### Что нового:
- 🏙 **Вид сверху** — полноценная карта города с улицами и зданиями
- 🏠 **Здания** — дома, магазины, кафе, парк с фонтаном
- 🧑 **Рисованные человечки** — анимированные персонажи с головой, телом, руками и ногами
- 🐕 **Враги** — бродячие собаки и призраки патрулируют улицы
- 💬 **NPC** — 5 жителей города дают подсказки
- 🔑 **Ключи** — собери 3 ключа, чтобы открыть путь к цели
- 🗺 **Мини-карта** — ориентация в городе
- 🕹 **Джойстик** — виртуальный стик для мобильного управления

## 🎮 Управление

### Мобильное:
- **Виртуальный джойстик** (левый нижний угол) — движение в 4 направлениях

### Клавиатура:
- **WASD** или **стрелки** — движение

## 🗺 Карта города

Город состоит из 6 кварталов, разделённых дорогами:
- Жилые дома 🏠
- Магазины (цветы, книги, игрушки, музыка) 🛒
- Кафе и рестораны (пиццерия, пекарня, чайная) ☕
- Парк с фонтаном 🌳
- Особняк и башня 🏰

## 📱 Развёртывание

### Быстрый старт:
```bash
cd dist && python3 -m http.server 8080
```

### Nginx на Ubuntu:
```bash
sudo apt install nginx -y
sudo cp -r dist/* /var/www/game/
sudo ufw allow 80/tcp
```
